# NIUNIU AI 1.3.8

发布日期：2026-08-12

## 接口设置

- 新增 BBAPI 中转站、OpenAI、OpenAI 兼容、火山引擎和 Nano Banana 内置预设；选择后自动带入可确定的 Base URL。
- BBAPI 使用专属邀请注册链接；OpenAI、火山引擎和 Nano Banana 提供对应的 API Key 申请入口。
- 接口配置输入框任意位置均可展开列表，不再要求点击右侧箭头。
- 深色模式下 OpenAI 使用白色官方图标、火山引擎使用彩色图标、Nano Banana 使用黄色香蕉图标；图像、文本和视频模型列表同步显示对应品牌。

## 尺寸与局部编辑

- 文生图、图生图、局部修复和扩展填充分别保存尺寸比例，模式切换时不再互相覆盖。
- 局部修复固定当前 Photoshop 原图比例；扩展填充选择横向比例后，切回局部修复仍恢复原图比例。
- 修复扩展填充返图非等比拉伸、人物和画面变扁的问题；未编辑区域在本地合回原图，改善蒙版边缘衔接。

## 在线更新

- 更新安装使用内置 SHA-256 与 ZIP 处理，修复 Photoshop 环境下命令缺失和错误信息乱码。

## 更新说明

- 扩展 ID 保持不变；本次更新不会清理图片缓存、接口配置、API Key、登录状态或 Photoshop 文档。
