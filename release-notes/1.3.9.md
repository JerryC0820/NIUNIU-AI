# NIUNIU AI 1.3.9

发布日期：2026-08-12

## 模型与接口

- 主模型列表可汇总全部已配置接口的图像模型，并保留每个模型的接口来源；同名模型可按不同来源分别选择。
- 模型列表显示 OpenAI、即梦、Nano Banana 和 BBAPI 品牌图标；BBAPI 使用官方品牌资源。
- 设置中可关闭全接口汇总，只使用当前接口；用量与生成记录拆分为独立页面。
- BBAPI 等兼容接口会展示接口真实返回的模型额度字段；火山引擎可使用单独的账户 AK/SK 查询真实调用量。

## 提示词

- 反推与润色可在主界面切换自动模式或指定“接口 + 文本模型”，自动模式会跨已配置接口降级。
- 新增快速、标准、精细三档精度，精简、标准、详细三档长度，并可指定提示词最终用于 OpenAI、即梦或 Nano Banana 等图像模型。
- 自动路由会按精度选择更合适的视觉模型；参考图在上传前按档位压缩，失败重试具有单次和总等待上限。
- 反推继续忽略水印、平台标识、签名和二维码，避免把水印描述带入后续生成。

## 扩展填充

- 扩展填充的 API 蒙版和本地合成蒙版改为独立渐变重叠带，减少原图与扩展区域之间的硬边和亮缝。
- 保持原图区域的本地像素保护，不依赖模型重新生成未编辑区域。

## 更新说明

- 扩展 ID 保持不变；在线更新不会清理图片缓存、接口配置、API Key、登录状态或 Photoshop 文档。
