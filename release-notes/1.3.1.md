# NIUNIU AI 1.3.1

发布日期：2026-08-11

## 图像生成稳定性

- 修复 OpenAI 兼容接口接收大尺寸 Base64 参考图时可能出现的进程参数过长问题。
- OpenAI 图像接口使用 multipart 上传，火山引擎继续使用 Base64 JSON，请求格式按协议自动选择。
- 失败任务会清理未完成占位，不再留下无法选中或插入的半成品。
- 生成中状态补齐模型图标、状态文案和稳定动画，消除旋转方块边缘闪黑。

## Photoshop 编辑工作流

- 新增快速获取全图、当前图层和当前选区。
- 新增局部修复、去除文字和扩展填充。
- 选区可生成蒙版，结果支持羽化后回插，尽量保留选区外原图。
- 参考图支持大图预览，比例按钮恢复横向、竖向和正方形方向提示。
- 图生图新增原尺寸比例。

## 模型与接口

- 新增可编辑的多 API 配置、Base URL、API Key 显隐复制、模型获取和连通性测试。
- 图像模型和文本模型分别管理，文本模型可用于提示词润色和图片反推。
- OpenAI 模型使用白色 ChatGPT / OpenAI 花结图标和紫蓝青主题。
- Nano Banana 模型使用官方香蕉标识和黄色主题。

## 账户、后台与更新

- 新增个人中心、邮箱验证码登录、微信扫码登录、头像、会员、积分和生成记录。
- 新增静态管理台、用户管理、会员审核、费用统计、权限和审计记录。
- 新增腾讯云与 GitHub 双源在线更新、SHA-256 校验、暂停/继续和原位覆盖更新。
- 扩展 ID 保持不变，升级不会主动清理历史缓存。
