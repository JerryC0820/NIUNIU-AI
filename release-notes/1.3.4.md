# NIUNIU AI 1.3.4

发布日期：2026-08-11

## 局部编辑

- 局部修复、去除文字与选区扩展支持半透明红色蒙版预览。
- 返图可自动或手动插入 Photoshop，并按原选区创建可编辑图层蒙版。
- 支持选区扩边与羽化，未选区域继续保留原图内容。
- 优化 Photoshop 2025 中的蒙版回插流程，减少重复通道刷新与无效缩放。

## 生成队列

- 新增可切换任务队列，可连续提交多个任务并查看模型、状态与耗时。
- 支持单独取消当前任务，不影响其他正在生成的任务。
- 修复请求失败或本地缓存不可用后返图持续模糊、按钮无法使用的问题。

## 4K 与兼容性

- 非原生 4K 模型先请求最高可用规格，再按所选比例输出约 1600 万像素文件。
- 局部修复与扩展填充的 4K 超分保持原文档或目标画布比例。
- 原生 4K 模型不再重复执行本地超分。
- 修复普通浏览器预览时宿主桥初始化中断，保留 Photoshop CEP 宿主能力。

## 更新

- 扩展 ID 保持不变，升级不会主动删除历史图片、接口配置或 Photoshop 文档。
- 在线更新继续提供腾讯云与 GitHub 双下载源及 SHA-256 校验。
