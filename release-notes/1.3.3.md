# NIUNIU AI 1.3.3

发布日期：2026-08-11

## Photoshop 与相册

- 修复 Photoshop 宿主脚本未可靠加载导致的图层、选区和全图获取失败。
- 恢复相册插入新图层、替换当前图层和打开为新文档。
- 选区获取不再经过系统剪贴板，避免大图操作长时间阻塞 Photoshop。
- 图生图未添加参考图时，按选区、当前图层、全图自动降级获取。

## 生成与缓存

- 提示词润色与图片反推会自动选择可用文本或视觉模型，并在上游不可用时受控降级。
- 非原生 4K 图像模型可先生成最高可用规格，再在本地输出约 1600 万像素的 4K 超分文件。
- 优化启动和相册历史加载，避免大缓存同步扫描阻塞界面。
- 修复历史异步加载覆盖本轮新生成记录的竞态。

## 更新

- 扩展 ID 保持不变，升级不会主动删除历史图片、接口配置或 Photoshop 文档。
- 在线更新继续提供腾讯云与 GitHub 双下载源及 SHA-256 校验。
