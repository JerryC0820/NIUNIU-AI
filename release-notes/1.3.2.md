# NIUNIU AI 1.3.2

发布日期：2026-08-11

## 接口与模型

- 接口名称可直接编辑，Base URL 与 API Key 保存后自动识别协议并分类图像、文本和视频模型。
- 修复已删除接口被云同步重新带回的问题，登录账户可加密同步接口配置。
- 完善 OpenAI、Nano Banana 与即梦模型图标、主题和 1K / 2K / 4K 能力判断。
- 提示词反推会忽略水印、签名、二维码与非主体文字。

## Photoshop 与相册

- 优化全图、图层和选区获取流程，避免在 Photoshop 主线程同步处理大尺寸 Base64。
- 完善局部修复、去除文字、扩展填充、选区蒙版、羽化和局部回插。
- 修复相册插入、替换、打开文档、拖入参考图和复制位图交互。
- 失败任务会清理未完成占位，生成状态可在账户记录中恢复。

## 账户与管理

- 登录会话默认保留 30 天，微信扫码补齐加载、失效和重新获取状态。
- 新增客服微信二维码、QQ 与用户群二维码预留入口。
- 管理台支持用户状态、会员、角色和到期时间行内修改，并新增用户详情视图。
- 云端仅同步生成状态、提示词、模型、费用和参数，不保存生成图片。
- 管理台不再显示内部服务地址或数据库路径。

## 更新

- 在线更新继续提供腾讯云与 GitHub 双下载源、SHA-256 校验、暂停和继续。
- 扩展 ID 保持不变，升级不会主动删除历史缓存、接口配置或 Photoshop 文档。
