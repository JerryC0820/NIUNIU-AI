# NIUNIU AI 1.5.3

发布日期：2026-08-14

## 账号联动

- 登录 PSEX 后静默创建或绑定对应的 BBAPI 身份，无需再进入中转站手工关联。

## API 实验室

- Codex 授权完成后自动上传账号、创建或复用专属 API Key、导入接口并设为当前选中接口。
- 移除 BBAPI 人工关联以及上传账号、获取 Key、导入接口等手工配置步骤。
- 修复账号配置请求悬挂或持续重试时一直显示“正在配置”的问题，手动刷新可重新开始配置。
- 按 BBAPI 的真实窗口周期显示 5 小时、7 天、月度与附加额度，并显示 Plus、Team、K12 等账号套餐。

## 修复

- 修复已登录用户仍显示登录遮罩的问题，并在头像菜单中补充 API 实验室入口。
- 修复图片反推被重复接口配置占满尝试次数，以及单模型真实错误被笼统提示覆盖的问题。
- 修复提示词模型下拉在窄面板中被左右裁切的问题。
- 修复中英文切换后设置页、主功能区和动态状态未立即同步的问题。

## 管理后台

- 新增活跃用户、当前在线、生图并发、请求趋势和时段热力图统计。
