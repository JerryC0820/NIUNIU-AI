# NIUNIU AI 1.5.4

发布日期：2026-08-14

## 接口预设

- 新增 DeepSeek、OpenCode、Grok、Kimi、Gemini、GLM、阶跃星辰与 MiniMax 预设。
- 完善无密钥接口、服务商品牌识别及跨设备配置同步。

## 配置引导

- 启动引导时可选择要配置的服务商。
- 修复接口选择整行、展开菜单和目标预设的高亮及点击范围。
- 修复“上一步”在动态步骤中无法稳定返回的问题。
- 引导、服务商展示名和额度操作支持中英日即时切换。

## API 实验室

- 每个 Codex 账号固定显示 5 小时和 7 天已用额度。
- 增加单账号手动刷新、重置次数和额度重置操作。
- 修复上游只返回部分额度窗口时覆盖完整缓存的问题。
