# NIUNIU AI 1.4.5

发布日期：2026-08-13

## 官网

- 按统一深色创作工具视觉重建首页、在线版、版本说明和个人中心。
- 首页新增真实组件构成的 Photoshop 与插件工作流预览。
- 在线版新增模式、参数、历史缩略图、缩放、生成预览、项目保存和图片导出交互。
- 版本说明页从稳定版清单读取版本、安装器大小、下载地址和 SHA-256。
- 个人中心接入真实邮箱与微信登录、账户资料、会员、积分、绑定状态和生成记录。

## 更新说明

- 插件头像菜单的“关于”入口直接显示当前版本号。
- 关于页改为居中布局，新增官网、版本说明、公开发行与客服入口，并补充运行环境、更新策略和许可信息。
- 官网四页的 CSS 与 JavaScript 使用 V1.4.5 资源指纹，避免发布后旧缓存造成样式错配。
- 官网根地址保持为 `https://nai.ainivox.cn/`，管理台继续位于 `/admin`。
- 在线更新继续优先使用腾讯云，失败后自动切换 Cloudflare。
- 本次更新不清理图片缓存、接口配置、API Key、登录状态或 Photoshop 文档。
