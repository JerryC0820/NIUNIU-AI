NIUNIU AI 将文生图、图生图、局部重绘和扩展填充直接带入 Photoshop 工作流。你可以继续使用熟悉的图层、选区和蒙版，不必在 Photoshop 与网页工具之间反复导出、下载和复制图片。

## 功能概览

### Photoshop 原生工作流

- 读取当前 Photoshop 文档、当前图层或当前选区作为输入。
- 生成结果可预览、对比，并按需要回插到当前文档或新图层。
- 支持选区、蒙版、羽化和透明区域，便于保持原有构图与边缘关系。
- 适合海报、商品图、人像、概念图、社交媒体素材等日常设计场景。

### AI 生成与编辑

- 文生图：根据提示词生成全新画面。
- 图生图：以当前画面或参考图为基础进行风格、内容和构图调整。
- 多参考图：同时提供多张参考素材，辅助统一人物、产品或视觉风格。
- 局部编辑：只修改选区内的内容，适合换背景、改服装、补细节、去除文字或物体。
- 扩展填充：向画布外扩展画面，补齐背景、改变画幅比例或制作横竖版素材。
- 批量生成：一次提交多个结果，统一查看缩略图并挑选最合适的版本。

### 多接口与模型管理

- 支持火山引擎、OpenAI 兼容协议、Nano Banana / Gemini 等接口类型。
- 可保存多个接口配置，在插件内独立切换服务，不会因为 Photoshop 外部选择了其他模型而锁定当前配置。
- 图像模型与文本模型可以分别选择，满足“一个接口生成图片、另一个接口润色提示词”的组合需求。
- 支持在线获取模型列表、连通性测试、图像测试和文本测试。
- 可设置 Base URL、API Key、图像模型、文本模型及常用生成参数。

### 提示词、记录与账户

- 提示词润色，帮助把简短描述整理成更适合生成的提示词。
- 参考图提示词反推，方便分析已有画面的主体、风格和构图。
- 生成队列、任务取消、进度反馈和结果缩略图预览。
- 历史记录、本地缓存和参数保存，方便重复使用成功方案。
- 支持邮箱与微信账户登录；登录后可同步轻量生成记录、参数和会员状态。

## 安装

1. 在[官网](https://nai.ainivox.cn/)或 [Releases](https://github.com/JerryC0820/NIUNIU-AI/releases) 下载最新安装器。
2. 下载后按发行页提供的 SHA-256 校验值验证文件完整性。
3. 运行 `NIUNIU-AI-Setup-x.x.x.exe`，按安装向导完成安装。
4. 重启 Photoshop，在 `窗口 → 扩展功能` 中打开 **NIUNIU AI**。

如果 Photoshop 已经打开，安装或升级完成后请完全退出并重新启动 Photoshop，避免旧的扩展缓存继续生效。安装后可在“关于”页面查看当前版本。

## 首次配置

### 1. 登录账户（可选）

登录用于同步轻量记录、会员状态和设备信息。不登录也可以在本机保存接口配置并使用已配置的服务。

### 2. 添加接口配置

打开插件右上角设置，进入“接口”页面：

1. 在接口下拉框中选择已有配置，或点击新增配置。
2. 填写配置名称、Base URL 和 API Key。
3. 选择图像模型与文本模型；两个模型可以来自不同接口。
4. 点击“获取模型”确认服务可用，再分别进行图像或文本测试。
5. 保存设置，在生成面板中选择要使用的接口和模型。

每个配置单独保存自己的地址、密钥和模型。切换接口只会改变当前任务的服务，不会覆盖其他配置。

### 3. 进行第一次生成

1. 在 Photoshop 中打开图片，或新建一个空白文档。
2. 在插件中选择文生图、图生图或局部编辑模式。
3. 输入提示词，按需添加参考图、选择模型、尺寸和生成数量。
4. 点击“立即生成”，等待结果出现在预览区。
5. 选择满意的结果，回插到当前文档或新建图层继续编辑。

## 局部编辑与扩展填充

### 局部编辑

1. 在 Photoshop 中建立选区，必要时使用羽化让边缘过渡更自然。
2. 将选区或当前图层发送到 NIUNIU AI。
3. 描述希望替换、补充或删除的内容。
4. 生成多个候选结果，比较后将选中的结果回插到原位置。

### 扩展填充

1. 先把画布扩展到目标比例，保留需要补齐的透明区域。
2. 选择扩展填充并输入背景、构图或镜头方向要求。
3. 生成后检查边缘、透视和光影衔接，再回插到新图层进行微调。

## 接口切换与常用设置

- 在“接口”页面切换配置，可在不同服务之间快速切换。
- 在生成面板切换图像模型；文本模型用于提示词润色和文本相关能力。
- 需要更换服务商时，新增一条配置即可，不必修改原配置。
- “获取模型”失败时，优先检查 Base URL 是否包含正确的兼容路径、API Key 是否有效，以及网络是否可访问。
- 测试通过后再开始批量生成，能更快定位地址、权限或模型名称问题。

## 更新机制

插件检查更新时优先使用腾讯云正式源；腾讯云暂时不可用时才切换公共备源。安装包会提供 SHA-256 校验值，更新过程只替换运行文件，不删除历史生成缓存、接口配置、账户状态或 Photoshop 文档。

更新后若界面仍显示旧版本，请完全退出 Photoshop 后重新打开插件，再在“关于”页面查看版本号和更新内容。

## 兼容环境

- Windows 10 / 11
- Adobe Photoshop CC 2015–2026
- Adobe CEP 扩展运行环境

Photoshop 2027 已预留版本范围，但目前仅做前向兼容设计，尚未完成 Photoshop 2027 实机验证。不同 Photoshop 版本的 CEP 运行环境、系统权限和显卡驱动可能影响具体表现；遇到界面异常时，请先升级到最新安装包并重启 Photoshop。

## 常见问题

**插件没有出现在扩展菜单中**

确认安装已完成，完全退出 Photoshop 后重新启动，并检查 Photoshop 是否允许 CEP 扩展运行。

**获取不到模型或测试失败**

检查 Base URL、API Key 和模型名称；先点击“获取模型”，再进行文本或图像测试。若使用第三方中转服务，请同时确认账户额度和服务商的接口路径要求。

**生成结果没有回到 Photoshop**

确认当前文档仍处于打开状态，并在 Photoshop 中保留可编辑的目标图层或选区。必要时关闭并重新打开插件后重试。

**升级后仍显示旧界面**

退出 Photoshop（包括后台进程）后重新打开。若问题仍在，请卸载后安装最新版本，并保留本地配置前先备份重要设置。

## 数据与安全

- API Key 仅用于调用你配置的服务，不会提交到公开代码仓库。
- 未登录时，接口配置保存在本机；登录后可按账户同步轻量数据。
- 云端同步内容以生成记录、参数和轻量缩略图为主，原始大图默认保存在本地。
- 使用第三方模型或中转服务时，请遵守对应平台条款并自行确认计费、数据保留和隐私规则。
